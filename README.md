## Independent project: Qualinexus _(prototype)_
AI-assisted test automation platform.

- Takes existing test cases (CSV, Excel, Jira or typed requirements) and turns them into automated tests
- Generates positive, negative, boundary and regression cases and the Playwright scripts
- Runs on Chrome, Firefox and WebKit and reports results per requirement
- Asks for clarification when a requirement is too vague to test
- Self-heals when the UI changes: finds the new locator, reruns the test and waits for human approval before applying the fix
- Generates schema-validated test data
- Early prototype demonstrated on a sample store with synthetic data; no customers yet
